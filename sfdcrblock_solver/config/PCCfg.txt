# A txt description of a BlockConfig for a SingleFlowDCRBlock asking for the
# "P/C" (Perspective Cuts) formulation of the burst-delay terms, i.e., the
# one in which the two rotated cones are not constructed but dynamically
# outer-approximated by linear cuts. The formulation is therefore a
# relaxation of the problem as long as the cuts that separate the current
# point have not all been generated, which is why a Solver of this
# formulation is declared to solve a relaxation (see the -R option of the
# test) unless it separates the cuts itself.
#
